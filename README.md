# FaceVerificationProject

Система біометричної автентифікації за обличчям (магістерська робота, ЗУНУ, КНм-21), Django.

- **Реєстрація:** до 3 фото → Multi-Reference embedding (RetinaFace + ArcFace) → 2FA (TOTP, QR-код).
- **Вхід:** перевірка живості (моргання й повороти голови у випадковому порядку) → верифікація обличчя
  з динамічним порогом (вищий поріг, якщо виявлено маску) → після 3 невдалих спроб — лише OTP.
- **Бенчмарк:** точність на датасетах mfr2 (маски) і LFW — точність, FAR, FRR, EER.
- **Demo use case:** система проходження тестів (див. нижче).

## Запуск (Windows)

Потрібен Python 3.10. Віртуальне середовище лежить у `ImageVerificationProject\venv`.

```powershell
cd FaceVerificationProject
python -m venv ImageVerificationProject\venv          # лише якщо venv ще немає
.\ImageVerificationProject\venv\Scripts\python.exe -m pip install -r requirements.txt
.\ImageVerificationProject\venv\Scripts\python.exe manage.py migrate
.\ImageVerificationProject\venv\Scripts\python.exe manage.py runserver
```

Сайт: http://127.0.0.1:8000/. Камера працює лише за адресою `127.0.0.1` / `localhost`.
Після старту сервер ~1 хв прогріває моделі (у консолі з'явиться `[warm-up] Моделі готові`).

## Demo use case: система проходження тестів

Сценарій: викладач надсилає групі посилання-запрошення → студенти реєструються (обличчя + 2FA) →
викладач надсилає посилання на тест → студент входить обличчям або кодом 2FA → проходить тест → бачить результат.

| Що | Адреса |
|---|---|
| Запрошення на реєстрацію (одне на групу, багаторазове) | `/invite/<token>/` |
| Тест | `/tests/<id>/` |
| Окреме вікно входу до тесту (вибір студента) | `/tests/<id>/login/` |
| Результат спроби | `/tests/attempts/<id>/` |
| Керування тестами, питаннями, запрошеннями, спробами | `/admin/` |

Правила:
- Посилання на тест без входу відкриває окреме вікно входу: список зареєстрованих студентів → вхід обличчям
  (з перевіркою живості) або кодом 2FA. Після 3 невдалих спроб обличчям — лише код 2FA
  (оновлення сторінки ліміт не скидає).
- Вхід фіксується в сесії лише після успішної верифікації обличчям або OTP.
- У кожному питанні один правильний варіант (адмінка не дасть зберегти інакше).
- Кількість спроб не обмежена; зберігаються всі, на сторінці тесту показується останній результат.
- Результат спроби бачить лише студент, який її пройшов.
- Відкрита реєстрація (`/magisterjob/`) працює й без запрошення.

### Підготовка (один раз)

```powershell
$py = ".\ImageVerificationProject\venv\Scripts\python.exe"
& $py manage.py migrate
& $py manage.py createsuperuser                      # обліковий запис для /admin/
& $py manage.py seed_tests                           # 3 тести по 5 питань; друкує посилання на тести
& $py manage.py create_invite "КНм-21" --days 30     # посилання-запрошення; без --days діє безстроково
```

Тести й запрошення також можна створювати в адмінці (`/admin/` → «Тести», «Запрошення»):
питання додаються в тесті, варіанти відповідей — на сторінці питання. Посилання на тест і запрошення
показані у списках адмінки.

### Як пройти сценарій вручну

1. Запустіть сервер і дочекайтесь `[warm-up] Моделі готові` у консолі.
2. **Реєстрація за запрошенням.** Відкрийте посилання з `create_invite`. Над формою буде «Запрошення: КНм-21».
   Вкажіть ім'я латиницею (без пробілів), зробіть 1–3 фото камерою або завантажте файли → «Далі» →
   відскануйте QR-код застосунком-автентифікатором (Google Authenticator тощо) → введіть 6-значний код.
   Відкриється сторінка «Реєстрацію завершено».
3. **Вхід до тесту.** Відкрийте посилання на тест (наприклад, `/tests/1/`). Без входу відкриється вікно
   «Вхід до тесту»: знайдіть себе в списку і натисніть на своє ім'я.
4. **Вхід обличчям.** Пройдіть перевірку живості (кліпнути, повернути голову ліворуч і праворуч у
   випадковому порядку, дивитися прямо) → верифікація. Після успіху відкриється тест.
   - Перевірка запасного шляху: 3 рази поспіль покажіть камері інше обличчя або закрийте його —
     після третьої невдачі з'явиться поле OTP; введіть код із застосунку.
5. **Тест.** Позначте відповіді на 5 питань → «Завершити». З'явиться результат «N / 5» і відсоток.
   «Пройти ще раз» — нова спроба; на сторінці тесту видно останній результат.
6. **Вихід.** «Вийти» у правому верхньому куті. Після виходу тест знову вимагатиме вхід.
7. **Адмінка.** `/admin/` → «Спроби» — усі спроби студентів; «Запрошення» — скільки людей зареєструвалось;
   зніміть «Активне», щоб вимкнути посилання.
